# Security policy

Octet is under active development. Reports should identify the exact revision,
platform, configuration, and affected command. There is no promised response
SLA or long-term support window for historical revisions.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** action in the repository's Security tab:

<https://github.com/OnixResearch/octet/security/advisories/new>

This channel requires maintainers to enable private vulnerability reporting.
If it is unavailable, open an issue asking for a private contact channel
without disclosing exploit details, sensitive source, credentials, or private
receipts. Do not post a vulnerability reproduction publicly before coordinated
review.

Include the affected revision, prerequisites, minimal reproduction, expected
and observed behavior, and impact. Redact credentials and private input data.
License, lint, proof, and build results are scoped evidence, not a guarantee
that Octet or checked programs are secure.
