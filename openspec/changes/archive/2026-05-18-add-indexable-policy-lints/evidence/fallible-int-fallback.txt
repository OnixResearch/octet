## Implementation

Implemented `fallible_int_fallback` as a late safety lint in `src/safety/fallible_int_fallback.rs`.

The lint reports fallible integer conversions that immediately hide failure behind sentinel/default fallbacks:

- `u32::try_from(count).unwrap_or(0)`
- `u8::try_from(count).unwrap_or(u8::MAX)`
- `i32::try_from(count).unwrap_or(i32::MIN)`
- `u16::try_from(count).unwrap_or_default()`

The implementation verifies the receiver type is `Result<integer, _>`, so non-integer `Result` fallbacks are outside this lint. It also suppresses test-context code through the existing `test_context` helper.
