# Risk analysis

False coverage can hide an effect in a binary or test unit. Ambiguous crate names can attach facts to the wrong unit. Cargo unit-graph schemas can omit relevant configuration facts.

Use explicit source, test, feature, and target bindings. Reject ambiguous plans and unknown selected sessions. Bump internal collector context compatibility and reject old contexts. Keep compiler failures distinct from effect rejection.

The architecture maintainer owns source selection and generated-contract review. This work does not authorize tenant access, runtime effects, or broad consumer acceptance.
