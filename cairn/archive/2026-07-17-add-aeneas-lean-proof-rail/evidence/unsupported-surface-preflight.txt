# Unsupported-surface preflight slice evidence

Requirement: `r[octet.aeneas_lean_proof_rail.unsupported_surface]`

Implementation artifact: `crates/octet-standards/src/formal_proof.rs`

The pure preflight core now records typed inputs for unsafe Rust, concurrency,
unsupported loop-control, unresolved externals, and translation failure. It
classifies an empty input set as `ready`, unsupported source inputs as
`blocked`, and translation failure as `failed`. The payload validator rejects
mismatched recorded dispositions, and formal-proof promotion rejects every
non-`ready` disposition.
