## Design

Define an export row with source artifact directory, source receipt digest, Octet rail, Preserves schema label, canonical envelope digest, evidence role, consumer profile, and non-claims. The pure checker validates row shape and source linkage. The shell measures source receipts and serialized Preserves bytes.

The export command must require existing artifact verification success before producing or accepting a Preserves envelope. Preserves export is an adapter, not a new proof rail.
