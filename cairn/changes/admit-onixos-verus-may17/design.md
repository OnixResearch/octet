# Design

## Admission contract

The row may become `native` only because the exact published Octet candidate package exited zero over the exact OnixOS lifecycle model and reported `4 verified, 0 errors`. The consumed receipt must record `promotion_eligible = true`, `central_admission = false`, the pre-promotion `local-pin` row, zero errors, no timeout, no Trellis import, and `partial-verus-only` scope.

The profile update changes only `onixos-lifecycle`; Aspen remains `local-pin`. OnixOS retains source-model, execution, and receipt authority.

## Evidence

`evidence/onixos-candidate.md` records the candidate receipt identity, provider revision, OnixOS commit, observed result, and non-claim boundary. Octet's typed profile export and negative fixtures remain the fail-closed configuration rail.
