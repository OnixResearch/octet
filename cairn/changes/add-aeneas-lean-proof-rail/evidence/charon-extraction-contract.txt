# Charon extraction-contract slice evidence

Requirement: `r[octet.aeneas_lean_proof_rail.charon_contract]`

Implementation: `crates/octet-standards/src/formal_proof.rs`

The pure `validate_charon_extraction_contract` core compares observed policy
values with the generated Nickel profile and rejects errorful extraction,
borrow-check bypass, target metadata drift, MIR/drop/start selection drift,
include/exclude/opaque/transformation drift, and serialization-format drift.
Aeneas payload validation invokes this comparator before admission.
