# Aeneas provider-closure task evidence

Requirement: `r[octet.aeneas_lean_proof_rail.safe_execution]`

Task: package the exact provider closure and assert that the configured Charon
revision matches Aeneas's reviewed pin before execution.

Implementation artifacts:

- `flake.nix` adds pinned, non-flake Aeneas and Charon source inputs,
  `octet-aeneas-lean-provider-closure`, its identity-only app, and a focused
  positive/negative Nix check.
- `flake.lock` was regenerated with `nix flake lock`; it records Aeneas
  `bc2eb6f941369fa3c695e30598b5758b11e4f0de` and Charon
  `cb50ff16b9f1066b8a97dc06da704de2da2fa41c`.
- The provider derivation reads Aeneas `charon-pin`, compares its exact
  40-character revision to the reviewed Nickel profile, retains store-backed
  Aeneas/Charon source links, packages executable links for Aeneas, Charon,
  Lean, and Lake, and emits BLAKE3 identities for the pin, profile, and all
  four executables. The wrapper permits identity and pin checks only; proof
  execution remains owned by the bounded `cargo-octet` shell.
